## ■ 書籍の紹介

### 概要

『りあクト！ TypeScript で始めるつらくない React 開発』は 2018 年 10 月に初版を発行、それ以降 React のバージョンアップに合わせて改訂版を出し続け、本書で第 5 版となります。読者が開発現場で即戦力になれるようにすることを目指した内容となっており、実際にプロのエンジニアの方々から多くの支持をいただき、これまでに**シリーズ累計 3.5 万部**以上を売り上げています。

このリポジトリはその最新第 5 版のサポートページです。
書籍は【① 言語・環境編】【② React 基礎編】【③ React 実践編】の 3 部構成となっており、
